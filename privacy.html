Nuestros principios
✓
MIIA nunca lee lo que no le corresponde. Solo procesa mensajes de conversaciones donde está activa. Conversaciones privadas sin MIIA = invisibles.
✓
El admin nunca ve tus mensajes. El administrador de MIIA ve métricas agregadas (cantidad de mensajes, contactos), nunca el contenido.
✓
No vendemos datos. MIIA no comparte datos personales con terceros. Solo usamos proveedores esenciales (Google Cloud, Firebase, Gemini, Claude, OpenAI) con datos mínimos necesarios para generar respuestas.
✓
Derecho al olvido real. Al eliminar tu cuenta, se borran TODOS tus datos: negocios, contactos, sesiones WA, configuraciones, historial. Inmediato e irreversible.
✓
Menores protegidos. Menores de 13: supervisión obligatoria. 13-17: el owner decide el nivel de supervisión. Cumplimos con estándares de protección de menores.
✓
Auditoría permanente. Cada acceso a datos, exportación, cambio de configuración y evento sensible queda registrado con timestamp, actor y recurso.

Política de Privacidad

Datos que Recopilamos

Al utilizar MIIA, recopilamos y procesamos:

  • Datos de cuenta: nombre, correo electrónico, foto de perfil (vía Google Auth).
  • Datos de uso: fecha de registro, último acceso, plan contratado.
  • Datos de entrenamiento: la información que el Cliente proporciona para personalizar MIIA (productos, precios, instrucciones, palabras clave).
  • Datos de WhatsApp: mensajes de conversaciones donde MIIA está activada. Se almacenan temporalmente para contexto. MIIA no accede a conversaciones donde no interviene.
  • Datos de IA: al entrenar a MIIA, la información del negocio es procesada por modelos de IA para generar artefactos optimizados (prompts, FAQ, reglas). Se almacenan asociados al negocio del Cliente.

Cómo Usamos los Datos

  • Para operar y mejorar el servicio MIIA.
  • Para generar respuestas de IA personalizadas y relevantes al negocio del Cliente.
  • Para el proceso de Extracción de ADN comercial, solo si el Cliente otorga consentimiento.
  • Para generar estadísticas de uso y rendimiento del servicio.

Almacenamiento y Seguridad

  • En tránsito: HTTPS/TLS (cifrado extremo a extremo).
  • En reposo: AES-256 en Google Firebase (gestionado por Google Cloud).
  • Exportaciones: encriptadas con AES-256-CBC.

El acceso a los datos está restringido al personal autorizado de MIIA.

Compartición de Datos

MIIA no vende ni comparte datos personales con terceros, salvo:

  • Proveedores de infraestructura (Google Cloud, Firebase, Railway).
  • Proveedores de IA (Google Gemini, Anthropic Claude, OpenAI). MIIA selecciona automáticamente el proveedor según el contexto. Los datos enviados se limitan al contexto estrictamente necesario. Cuando el Cliente configura su propia clave de API, MIIA utiliza la clave del Cliente como proveedor principal.
  • Google Calendar API — solo cuando el Cliente conecta su cuenta de Google. MIIA accede exclusivamente a eventos del calendario para gestión de agenda.
  • Requerimientos legales o judiciales aplicables.

Claves de API del Cliente

Si el Cliente configura su propia clave de API de IA, MIIA la almacena de forma segura en Firestore y la utiliza exclusivamente para procesar las conversaciones del Cliente. MIIA nunca comparte, registra ni expone las claves del Cliente. Si la clave falla, MIIA utiliza sus propias claves de respaldo y notifica al Cliente.

Retención de Datos

Los datos se conservan mientras la cuenta esté activa. Al cancelar, se eliminan en un plazo máximo de 30 días, salvo obligación legal de retención.
